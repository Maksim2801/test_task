Структура проекта
    app/ — директория с исходным кодом приложения.
        main.py — основной файл, содержащий маршруты API.
        crud.py — файл с функциями для работы с базой данных.
        models.py — модели SQLAlchemy для таблиц в базе данных.
        database.py — настройки подключения к базе данных.
    docker-compose.yml — файл для конфигурации Docker.
    Dockerfile — файл для сборки Docker-образа приложения.
    requirements.txt — файл с зависимостями проекта.
Стек технологий
    FastAPI — современный веб-фреймворк для Python, используемый для создания REST API.
    SQLAlchemy — ORM для работы с PostgreSQL.
    PostgreSQL — реляционная база данных.
    Docker — контейнеризация приложения.
    Uvicorn — ASGI сервер для запуска FastAPI приложения.



    Установка и запуск
1. Клонирование репозитория

    Для начала клонируйте репозиторий:

    git clone https://github.com/Maksim2801/test_task.git
    cd organization-directory

2. Создание и настройка окружения

    Убедитесь, что у вас установлен Docker и Docker Compose. Если они не установлены, следуйте инструкциям на официальном сайте Docker:

    Установите все зависимости проекта (локально или внутри виртуального окружения, если необходимо):

    pip install -r requirements.txt

3. Запуск контейнеров

    Соберите и запустите контейнеры с помощью Docker Compose:

    docker-compose up --build

    Это создаст контейнеры для вашего приложения и базы данных PostgreSQL.

    После того как контейнеры будут запущены, откройте браузер и перейдите по адресу:

    http://127.0.0.1:8000/docs

    Здесь вы сможете протестировать API с помощью интерактивной документации Swagger.

4. Применение миграций

    После первого запуска контейнеров необходимо применить миграции к базе данных. Для этого выполните следующую команду:

    docker-compose exec app alembic upgrade head

    Это применит все миграции, создавая необходимые таблицы в базе данных PostgreSQL.

5. Остановка контейнеров

    Когда вы завершите работу, остановите контейнеры с помощью команды:

    docker-compose down
